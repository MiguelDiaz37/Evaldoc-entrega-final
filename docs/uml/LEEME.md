# Diagramas UML de EvalDoc

En `imagenes` están los diagramas en PNG y en `codigo_lucidchart` el código Mermaid de cada uno:

- `01_casos_de_uso`: casos de uso
- `02_clases_dominio`: clases del dominio
- `03_clases_servicios`: clases de los casos de uso y sus puertos
- `04_secuencia_publicar`: secuencia para publicar una evaluación con moderación
- `05_secuencia_login`: secuencia para iniciar sesión con código
- `07_modelo_bd`: modelo relacional de la base de datos

Para abrirlos en Lucidchart: crea un documento, haz clic en el ícono de código (`</>`), elige Mermaid y pega el contenido del archivo `.mmd`. Lucidchart acomoda las cajas a su manera, así que pueden quedar en otra posición que en la imagen, pero el contenido es el mismo.

La imagen de casos de uso se hizo con Graphviz (`fuentes_graphviz`), porque Mermaid no tiene ese tipo de diagrama.
